<h2 align="center">ReceiptFold</h2>

<h4 align="center">收據、明細、發票、會員載具於一身的記帳管理工具。</h4>

[![GitHub License](https://img.shields.io/github/license/oniyukai/ReceiptFold)](https://github.com/oniyukai/ReceiptFold/blob/main/LICENSE)
[![GitHub Release](https://img.shields.io/github/v/release/oniyukai/ReceiptFold.svg)](https://github.com/oniyukai/ReceiptFold)

## 功能亮點

### 跨平台支援
使用 Flutter 跨平台開發。

- Android、Windows
- [ ] Linux
- [ ] iOS
- [ ] MacOS

### 收據紀錄
- 期別瀏覽
- 新增編輯: 完整收據與明細欄位可增改、排序。
- 進階搜尋: 依狀態、日期、金額、關鍵字等多重條件自訂搜尋。

### 掃描對獎
- 期別對獎: 一鍵對獎該期紀錄，顯示中獎張數與總獎金。
- 手動對獎: 輸入發票號碼末 3 碼，即時比對近期開獎號碼。
- 掃描發票: 鏡頭影像即時辨識，同時解析傳統發票、電子發票，並對獎與存檔。
- 瀏覽號碼: 按期別瀏覽保存曾經取得過的開獎獎號資料。

### 會員載具
- 條碼展示: 展示會員載具時可選自動調亮螢幕與螢幕方向鎖定。
- 會員卡條碼: 支援新增 QR Code、DataMatrix、Code128 等格式，並可自訂縮圖網址。
- 載具條碼: 支援新增多組條碼快速切換展示掃描。
- 歸戶載具: 手動本地新增，或與雲端發票同步。
- 桌面小工具: 會員卡與手機載具可直接加到主畫面 (限定 Android)。

### 特色
- 外觀: 選定色彩或 Material You 動態色彩、背景淺色/深色/跟隨系統的 Material Design 3 介面。
- 多語言: 目前支援中文、英文、日文 (含 AI 翻譯內容)。
- 雲端發票: 內建 WebView 網頁登入，輔助記錄下中獎發票、歷史發票、載具清單，亦可以匯入彙整 CSV。
- 備份同步: 可與裝置文件或以 WebDAV 進行存檔備份或資料同步。
- 隱私無廣告: 無廣告無追蹤，所有資料皆由使用者自主控制，不進行商業利用。
